# 付费歌曲续听 1.0.0

![插件图标](icon.svg)

EchoMusic 的公开同曲与关联 MV 音轨兜底插件。原歌曲不可播放时，尝试可公开播放的同曲或宿主关联 MV，并自动检索和核验更合适的歌词版本。

## 功能

- 网易云、QQ 公开完整同曲兜底，匹配标题、完整歌手及版本，排除付费和试听候选。
- 复用 EchoMusic 内置 MV 音轨兜底，按实际 MV 时长播放；不修改原平台的付费权限。
- 按歌名、歌手和 MV 时长检索歌词，多候选共用一次本地识别结果，核验成功后替换并缓存。
- 图标显示检索、校准和完成状态；悬停查看来源，状态变化有 toast 提示。
- 切回原音源或停用时恢复原歌词及显示状态。

## 安装

适用于 **Windows x64、EchoMusic 2.3.2-beta.20 及兼容的 2.x**。在“插件管理”安装，或下载本目录，完整复制到插件目录。保留 bin 和 analysis 目录，重新启用插件。

完整组件约 **69 MiB**，使用 whisper.cpp 与 Base Q5_1 模型，无需安装 Python、Node.js 或额外 FFmpeg。系统需具备 Microsoft Visual C++ x64 运行库。启用时按宿主提示允许本地识别程序。

## 歌词与音轨说明

首次候选歌词需自动核验；成功缓存后可直接恢复，无需再次加载 MV。匹配证据不足时保留原歌词，仍可能与 MV 不同步。整体偏移无法修复不同剪辑、变速和中途插入；儿歌童声与重复短句也可能无法可靠匹配。

MV 的前奏、剧情、旁白和片尾保留。本插件不裁剪或分离实际音轨，也不会解锁付费音源。

检索使用宿主歌词接口。识别在本机完成，不向识别服务上传音频或歌词。完整使用方式、权限和实测边界见 [使用说明](使用说明.md)。

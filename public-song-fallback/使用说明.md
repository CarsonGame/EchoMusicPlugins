# 付费歌曲续听 1.0.0

付费或不可用歌曲无法直接播放时，自动尝试关联 MV 音轨，配合公开同曲匹配与歌词校准，让播放更连贯。插件 ID 保持 `public-song-fallback`，旧版缓存及播放栏位置继续保留。

适用于 Windows x64 / EchoMusic 2.3.2-beta.20 及兼容的 2.x。完整组件约 69 MiB，无需安装 Python、Node.js 或额外 FFmpeg。首次安装需要保留整个 `bin` 目录；不能只复制入口文件。官方原生程序需要系统具备 Microsoft Visual C++ x64 运行库，缺少时需安装微软官方 x64 运行库。

## 使用与更新

1. 将完整包中的 `public-song-fallback` 文件夹放入“插件管理 → 打开目录”的插件目录；升级时覆盖已有同名目录。
2. 启用“付费歌曲续听”。升级后先停用再启用，或重启 EchoMusic。
3. 首次启动新版识别程序时，允许宿主提示的 `bin/whisper-cpp/whisper-cli.exe`。这是 EchoMusic 按插件版本和可执行文件校验授权的要求。
4. 正常播放歌曲即可；解析失败时自动尝试公开同曲及宿主关联 MV 音轨。

从先前开发版升级时，覆盖同名插件目录后重新启用即可。插件 ID 不变，成功缓存继续保留；无需重新下载未改变的模型。

若曾安装开发版的大型识别组件，可停用插件后移除旧 `bin/lyric-aligner`、`bin/models/whisper-small`，再覆盖完整包；保留用户缓存。

默认安装位置：`%APPDATA%\echo-music\plugins\public-song-fallback`。更新保留校准缓存，不修改歌曲、设置或歌单。

## 图标、悬停与 toast

采用兜底音源后，播放栏只显示图标，不显示常驻文字。校准时外圈旋转，完成后显示勾选，失败显示提醒；悬停查看来源及当前状态。来源和校准状态变化时弹出一次 toast，相同状态不重复弹出。图标位置沿用用户保存的播放栏布局。

## 优先检索 MV 匹配歌词

- 等待播放器提供当前 MV 的实际时长，再按“歌名＋完整歌手＋MV 时长”搜索；不以原歌曲的专辑时长代替。
- 仅保留同标题、同歌手且时长差不超过 1.5 秒的候选，优先时长最接近者，最多获取 3 份歌词。相同主歌词时间轴去重。
- 复用宿主解析器，保留逐字、翻译和音译，拒绝空文本、倒序或超出 MV 范围的时间轴。
- 搜索候选并非平台保证的 MV 专属歌词，时长接近也不证明同步。首次仍通过本地识别核验，所有候选与原歌词共用识别结果，不按候选数量重复下载或识别 MV。
- 候选通过与原歌词相同的多锚点、一致偏移及跨度检查后，优先覆盖当前歌词，显示“已匹配 MV 歌词”，必要时自动补充整体偏移。
- 成功候选及核验结果按歌曲、MV 媒体文件、实际 MV 时长和原歌词内容缓存。再次命中直接恢复，不检索、不下载 MV、不启动识别。
- 无可靠候选时回退原歌词校准；搜索失败也会回退。旧版成功偏移缓存继续保留并可作为回退结果。
- 切回原音源或停用时恢复原歌词、翻译和音译显示状态、原始文本及候选标记，不写入宿主为原歌曲保存的手动歌词选择或偏移。迟到结果不覆盖下一首。

本版接入的是歌词搜索与自动核验，尚未取得由平台明确绑定到 MV 的独立字幕接口，不提取画面烧录字幕。首次检索仍可能需要加载 MV 音频做核验；成功缓存后免核验。

## 轻量自动歌词校准

- 本版采用两线程识别，减少本机六线程对照中出现的长时间等待；具体速度受歌曲内容和系统负载影响。
- 原生识别：whisper.cpp + Base Q5_1 多语言量化模型；先前 small 模型和大型 Python 依赖已不再需要。
- MV 下载到内存，由 Chromium 内置解码器提取音频并采样至 16 kHz；不显示视频，也不上传音频或歌词到识别服务。
- 长歌优先分析前 90 秒，先过滤无人声的前奏；依据初步偏移选择后段约 60 秒独立复核，后段不过滤较弱歌声。没有足够独立复核区间的短歌直接完整识别，避免先后重复分析。
- 两段各自通过多句歌词、一致偏移和匹配跨度检查，合并后仍通过检查，才应用校正。匹配门槛与旧方案一致，不按 MV 与原曲总时长差猜测。
- 证据不足时，使用同一小模型按最多 120 秒一块扩大到全曲识别。仍不可靠则显示“未校准”，不强行应用。
- 匹配时统一繁简和单个数字的常见写法，例如“2隻”和“两只”；显示的歌词文本保持不变。
- 歌词数组重新创建但内容相同时继续使用当前任务；切歌、取消、识别异常均结束当前状态。单次原生识别最多等待 60 秒，整个流程最多等待 90 秒；超时显示“未校准（分析超时）”并弹出 toast，不再持续转圈。
- 这是整体时间平移，不能重排 MV 内的剧情、删节或变速。采样可能漏掉未检查区间的局部差异，识别也不能保证每首歌曲成功。
- 校正当前歌词的行、逐字及次级时间戳；不改变歌词文本、播放器全局偏移或原曲歌词。切换音源和停用插件时恢复原始时间轴。
- 成功结果按歌曲、MV 媒体文件与歌词内容保存到宿主的本地插件私有存储；已有开发版成功缓存继续复用，命中缓存无需下载或识别。
- 原生程序仅接收本机临时 PCM 文件，不接收媒体 URL、不监听本地端口。临时 WAV 与识别 JSON 正常完成、失败或取消后清理；运行中强制退出或断电可能留下临时文件。



这是单个样本的实测，不能保证所有 MV 的耗时和精度。小模型对复杂伴奏、语言和唱法的容错能力可能低于原先 small 模型；低置信度时保持原歌词，不用错误偏移换取速度。

如果平台提供该 MV 配套的带时间戳歌词或字幕，可以直接使用并免校准；当前接口未取到《关键词》MV 专属歌词，只返回约 208.6 秒原曲歌词，因此当前版本仍使用本地校准。

## 音源行为与限制

内置曲库失败后，插件并行匹配网易云与 QQ 的公开完整同曲。必须同标题、同歌手及合理时长，保留 Live、伴奏、Remix 等版本信息；付费、试听和权限不明确的候选会跳过。播放前检查媒体类型及完整文件大小，刷新播放链接，不复用过期签名。手动右键“检查公开同曲音源”仅用于检查。

MV 兜底复用 EchoMusic 自带功能。插件启用时打开 `mvAudioFallbackEnabled`，原曲、插件普通音源和云盘等后续普通音源仍优先于 MV。关联依据为宿主歌曲资源 ID，不会任意搜索同名视频。宿主筛选完整、已发布、非 UGC 的关联 MV，并优先使用推荐版本。

播放的是 MV 自己的音轨，时长同步 MV。剧情、旁白、环境声、前奏和片尾会保留，可能与专辑录音不同；不裁剪、不分离或改写实际播放音频。原曲付费标识仍描述原平台歌曲状态，不代表插件解锁了付费音源。

原生 MV 兜底开关是全局设置。停用或卸载插件不会自动关闭它；需要时可在“设置 → 播放”中关闭“音频播放失败时尝试 MV 音频”。

儿歌可能出现重句多、童声识别错误或 MV 与原曲结构不同的情况；当前模型不能保证自动校准。实测《两只老虎》未得到足够可靠证据，另有运行出现识别超时；《蜗牛与黄鹂鸟》两线程复测约 7.5 秒正常结束，但匹配证据不足，未强行校准；新版本会明确结束状态，不据此猜测歌词偏移。

## 数据与权限

公开同曲搜索只向平台发送歌曲元数据，不读取私人歌单或账号凭据，不调用第三方解锁服务。MV 请求由宿主正常接口处理。识别在本机运行，模型已随包提供，不在分析时下载模型。

`kugouApi` 用于调用宿主只读歌词接口；`unrestrictedNetwork` 用于平台 API 和媒体下载；`process` 用于启动本插件内的原生识别程序；`localFiles` 用于读写和删除 `alignment-cache/native` 内临时 PCM、JSON 文件。一次 WAV 不超过约 3.84 MB，符合宿主文件写入上限。成功 MV 歌词缓存包含歌词正文和核验指标，通常每首数 KB 至数十 KB；不保存音视频副本。宿主本地私有存储还保留一条 `last-alignment-diagnostic` 诊断记录，包含当前阶段、候选 ID、时长、匹配指标或错误原因，不含访问密钥、媒体地址或歌词正文，新的诊断覆盖旧记录。配置和门槛按用户要求集中在 `index.js` 的 SETTINGS、ALIGNMENT 中。

## 验证

66 项 JavaScript 检查通过，覆盖音源规则、实际来源提示、toast 去重、动画状态、缓存、跨曲隔离、时间平移、繁简匹配、多锚点门槛、变速／插入拒绝、PCM 编码及取消时进程和临时文件清理，另覆盖歌词副本刷新、全流程超时、校正后副本恢复和数字等价匹配。本版新增 MV 实际时长检索、同歌手和版本筛选、候选去重、首次替换、缓存恢复、完整元数据还原、原歌曲无歌词、检索失败回退及无关识别不覆盖检查。

独立浏览器模拟宿主的完整流程，使用真实公开 MV、Chromium 解码及随包原生程序验证通过；正常结束后临时 PCM／JSON 目录为空。图标旋转另经浏览器验证。尚未在 EchoMusic 窗口内实际试听或验证按钮布局。

发布前真实接口、MV 和原生识别复测：《关键词》回退原歌词并成功延后 21,800 毫秒，约 9.0 秒；《两只老虎》约 5.8 秒，80 秒候选实际参与核验但证据不足；《蜗牛与黄鹂鸟》约 8.2 秒，未强行替换。候选成功替换与缓存路径另通过可控识别样本验证，尚不能保证儿歌都成功。

依赖版本、来源、校验值及许可见 `analysis/`。官方插件指南：https://github.com/hoowhoami/EchoMusicPlugins/blob/main/docs/plugin-development.md
